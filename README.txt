VIVER BEM — ESCOLA GOTA DE MEL

Arquivos:
- index.html
- styles.css
- app.js

COMO TESTAR
1. Abra a pasta no computador.
2. Clique duas vezes no arquivo index.html.
3. Para testar no celular, publique os três arquivos no GitHub Pages ou em outra hospedagem.

COMO PERSONALIZAR
- Mensagens, piadas, memes, desafios e dicas ficam no início do arquivo app.js.
- Os conteúdos mudam automaticamente de acordo com o dia do ano.
- Para colocar a logo oficial, substitua o emoji 🌼 no cabeçalho por uma imagem.
- Para criar o QR Code, primeiro publique o site e depois gere o QR Code usando o endereço público.

OBSERVAÇÃO
As playlists abrem buscas no Spotify para evitar links quebrados ou dependência de uma playlist específica.
